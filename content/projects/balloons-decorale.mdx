## Context

The first version of the site was a gallery with a contact link, which meant
every enquiry arrived as a blank email. Version 2.0 reorganises the work around
the two questions clients actually ask: *what can this look like* and *what
would it cost*.

## What I built

- A catalogue where each setup carries its event type, palette and scale, so
  the grid can be filtered without loading a new page.
- A quote request that collects event date, venue and budget range in steps,
  keeps its state if the tab is closed, and re-validates everything server-side
  before it sends.
- Transactional email through Resend, with a plain-text copy to the client so
  the enquiry exists in both inboxes.
- Image handling tuned for photography: AVIF first, sized per breakpoint, and
  never larger than the layout needs.

## Notable details

Colour is the whole product here, so the site gets out of the way — a neutral
shell, generous whitespace, and no interface chrome competing with the
photographs.
